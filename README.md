# Note Recognizer Flutter

Приложение для распознавания нот и аккордов по живому аудио с использованием локальной базы пользовательских эталонов. Основная идея — не только определять частоту сигнала, но сравнивать входящий звук с эталонными образцами, записанными пользователем. Это позволяет учитывать тембр инструмента, комнату, нестабильность вокала и акустические особенности среды.

## Что умеет приложение

- Захват аудио с микрофона Android
- Калибровка 12 нот хроматической гаммы
- Сохранение эталонных шаблонов локально
- Распознавание ноты по cosine similarity + fallback YIN-like pitch estimation
- Сборка аккорда в режиме арпеджио
- Виртуальная пианино-клавиатура
- Настройки, которые сохраняются между запусками
- Поддержка предупреждений о шуме, пустой базе и отсутствии микрофона

## Основные экраны

1. Главный экран распознавания
2. Калибровка
3. Настройки

## Быстрый старт

```bash
flutter pub get
flutter run
```

## Сборка release APK

```bash
flutter build apk --release
```

Готовый APK будет находится в:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## Минимальные требования

- Android 7.0+ (API 24)
- Микрофон
- Flutter SDK 3.3+
- Android Studio / IntelliJ IDEA

## Архитектура

- `lib/dsp` — DSP и обработка признаков
- `lib/services` — запись аудио, хранилище шаблонов и настроек
- `lib/pages` — экраны
- `lib/widgets` — UI-компоненты

## Примечание

Это прототип продукта для исследования и локального распознавания на устройстве. Для промышленных сценариев требуются более сложные алгоритмы, расширенная база шаблонов, обучение на большом наборе данных и калибровка под конкретные инструменты.
